Wähle eine Seite oder gib einen neuen Text ein – das Tool sortiert alle Seiten danach, wie nah sie inhaltlich verwandt sind.

1 Embeddings laden

CSV mit einer Spalte für die URL (z. B. Address) und einer mit dem Vektor (z. B. [0.012, -0.034, …]), etwa ein Screaming-Frog-Export. Die Datei bleibt auf deinem Rechner.

2 Vergleichen

    Der Text und der Key gehen nur an openrouter.ai, die CSV bleibt lokal.

    #SeiteÄhnlichkeitEinstufung

    Kosinus-Ähnlichkeit der Embeddings: 1 = gleicher Inhalt. Einstufung: sehr eng ≥ 0,90 · eng ≥ 0,80 · verwandt ≥ 0,70. Je nach Modell liegen die typischen Werte etwas anders. Klick auf eine Zeile macht diese Seite zum neuen Bezug.
